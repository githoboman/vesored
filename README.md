## ⚡ BOT Chain Overview

BOT Chain is an EVM-compatible Layer 1 blockchain optimized for DePIN and AI-native applications:
- **100% EVM Compatible**: Seamless migration for Solidity contracts and Ethereum tooling (MetaMask, Remix, Hardhat, Foundry).
- **Sub-Second Finality**: ~0.75-second block time for instantaneous portfolio tracking.
- **Ultra-Low Gas**: Average tx fees ~$0.06.
- **Native Utility Token ($BOT)**: Used for gas fees, validator staking, and on-chain governance.
