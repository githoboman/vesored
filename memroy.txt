1. EXECUTIVE SUMMARY & MIGRATION GOALS
================================================================================
Vesored is an AI-driven behavioral portfolio analytics and risk management
platform. The project has been fully migrated from legacy networks (ICP Canisters
and Injective Exchange modules) to BOT Chain.

Key Highlights of the Migration:
- 100% EVM Compatibility: Replaced Motoko with production-ready Solidity contract.
- Sub-Second Block Finality: Configured for ~0.75-second transaction confirmations.
- Ultra-Low Gas Fees: Average ~$0.06 transaction fees, ideal for frequent updates.
- Native Utility Token ($BOT & $tBOT): Full support for native balance and gas.
- Dual-Chain Ready: Pre-configured for Bohr Testnet (968) and Mainnet (677).
- EVM Wallet Support: 1-click connection for MetaMask, BO Wallet, and browser wallets.

3. COMPLETED CODEBASE MIGRATION AUDIT
================================================================================
A. Smart Contract Architecture (EVM):
   - Contract: `src/backend/contracts/VesoredPortfolio.sol`
     * `createOrUpdatePortfolio(btc, eth, usd, bot)`: On-chain portfolio state.
     * `getPortfolio()` / `getPortfolioOf(address)`: View portfolio balances.
     * `getRiskScore(address)`: On-chain algorithmic risk score (0 - 100).
     * `addTransaction(asset, amount, txType)`: Real-time transaction ledger.
     * `getTransactionHistory()`: User trade & transfer history.
     * Events: `PortfolioUpdated`, `TransactionRecorded`, `PricesUpdated`.
   - Deployment: `src/backend/scripts/deploy.js` & `hardhat.config.cjs`.

B. Frontend Web3 Provider Layer:
   - Client Library: `src/frontend/src/lib/botchain.ts`
     * EVM Wallet connection (`connectEVMWallet`, `switchToBotChain`).
     * Supports MetaMask, BO Wallet, Rabby, and EIP-1193 providers.
     * Automatic `wallet_addEthereumChain` / `wallet_switchEthereumChain`.
     * Direct JSON-RPC balance fetching via `eth_getBalance`.
     * Explorer link generators for Bohr Explorer (`https://scan.bohr.life`).
   - State Context: `src/frontend/src/context/WalletContext.tsx`
     * Tracks connected account (0x...), native balance (tBOT/BOT), chain ID.
     * Listens to `accountsChanged` and `chainChanged` events.
     * Seamless network switching between Testnet (968) and Mainnet (677).
   - Actor Bridge: `src/frontend/src/lib/botchainActor.ts`
     * Implements `backendInterface` without requiring ICP Canisters.
     * Handles portfolio state, risk calculations, and transaction records.

C. UI & Branding Migration:
   - `Header.tsx`:
     * Displays BOT Chain badge with live status.
     * Modal connects MetaMask, BO Wallet, and Browser EVM wallets.
     * Direct 1-click faucet access link (`faucet.botchain.ai/basic`).
     * Direct link to user address on Bohr Explorer.
   - `PortfolioCard.tsx`:
     * Displays BOT/tBOT allocation alongside BTC, ETH, and USD.
     * Real-time portfolio valuation based on live BOT Chain prices.
   - `PriceCard.tsx`:
     * Live price feed card for BOT Token ($BOT).
     * Loading state says "Fetching from BOT Chain...".
   - `BlockchainActivityPanel.tsx`:
     * Displays "Connected to BOT Chain (≈0.75s Finality)".
     * Live network badge: "BOT Chain Testnet".
     * Transaction status and full EVM 0x hash with copy and explorer button.
   - `TradePanel.tsx`:
     * Supports trading BOT Token alongside BTC, ETH, and SOL.
     * EVM 0x transaction hash generation (64-char hex).
     * Submission status: "Submitting transaction to BOT Chain (≈0.75s finality)...".
   - `TransactionsTable.tsx`:
     * MOCK_TRANSACTIONS updated with native BOT transactions.
   - `PortfolioAnalytics.tsx`:
     * Updated asset allocation and health insights for BOT token holders.
   - `App.tsx`:
     * Integrated `useBotChainPrices` hook.
     * Updated footer with BOT Chain ecosystem links (Explorer, Faucet, Docs).
